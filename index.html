Exporter vers Anki

Ce deck contient 18 cartes « grille entière » : recto = la situation (position + stack), verso = la grille couleur complète. C'est la meilleure façon d'ancrer les ranges dans Anki — tu reconstruis la grille de tête, tu retournes, tu vérifies. Le drill de ce trainer s'occupe déjà du travail main par main.

  1. Clique sur Télécharger le deck (.txt) ci-dessous.
  2. Dans Anki : Fichier → Importer, sélectionne le fichier.
  3. Type de note : Basique · Séparateur : Tabulation · coche « Autoriser le HTML dans les champs ».
  4. Champ 1 → Recto, Champ 2 → Verso. Importe.
